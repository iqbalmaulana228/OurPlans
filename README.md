# OurPlans ♡
A personal wedding planning dashboard: checklist, budget tracker, guest RSVP list, vendor directory and wedding-day timeline.

## Features
- Wedding date countdown and overview
- Editable planning checklist
- Budget estimates and expenses
- Guest list and RSVP tracking, CSV export
- Vendor shortlist and booking status, CSV export
- Wedding day schedule and calendar
- Local browser storage

## Deploy
Static site: deploy on Vercel with no build command and root directory.

All data is stored locally in the browser (localStorage).
